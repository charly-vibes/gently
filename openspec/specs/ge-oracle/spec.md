# oracle

The differential-testing capability: the original Perl Graph::Easy is the
**oracle**, and gently is only compatible if it reproduces the oracle's
outputs. This spec defines how oracle outputs are recorded, verified, and
kept honest — it complements [[ge.txt_render]] c4 (canonical-text
fixtures) by defining the mechanism and the environment contract.
Scratch fixtures and the runner plumbing use the genesis-vibes `fixture`
module; the recipes live in the repo justfile. Byte-compatibility is not
the universal comparison target: c7 scopes which claim classes the oracle
gates at all (decision record gently-ghh, designs/2026-10-09-decision-byte-compat-scope.md).

## Purpose

The differential-testing capability: the original Perl Graph::Easy is the
**oracle**, and gently is only compatible if it reproduces the oracle's
outputs. This spec defines how oracle outputs are recorded, verified, and
kept honest — it complements [[ge.txt_render]] c4 (canonical-text
fixtures) by defining the mechanism and the environment contract.
Scratch fixtures and the runner plumbing use the genesis-vibes `fixture`
module; the recipes live in the repo justfile. Byte-compatibility is not

## Constraints

| id | kind | expr | traces_to | observes |
|----|------|------|-----------|----------|
| c1 | invariant | The oracle is upstream Graph::Easy v0.69 at commit `ededa3d787ad89ac532c578c06390e8a7b270499`, invoked via perl; every recorded fixture carries a pin header naming that version and commit. | [[ge.oracle]] | |
| c2 | invariant | For every input in the shared fixture corpus, each supported output format has exactly one recorded expected output, generated by the oracle and committed alongside it. | [[ge.oracle]] | [[ge.oracle.c4]] |
| c3 | invariant | `just oracle-verify` re-renders every fixture input through gently and compares byte-identically to the recorded outputs; any mismatch fails naming the input, the format, and the first differing line. | [[ge.oracle]] | |
| c4 | effect | A missing or drifted oracle environment — perl absent, installed Graph::Easy version differs from the pin, or a stale pin header in a fixture — produces a typed error naming what is missing and the `just oracle-record` remediation. | [[ge.oracle]] | |
| c5 | invariant | `just oracle-record` regenerates recorded outputs for new inputs and updates pin headers in one pass; re-recording without a pin change is rejected as a non-deliberate change. | [[ge.oracle]] | |
| c6 | advisory | The fixture corpus exercises every edge style, border style, node shape, group form, flow direction, and label placement at least once. | [[ge.oracle]] | |
| c7 | invariant | Byte-compatibility claims are admissible only for fixture classes the pinned oracle produces deterministically: an input is in scope exactly when the pinned oracle renders it identically across repeated runs under the pinned seed (hash-stable) and records it within 10 seconds wall time (envelope); claims over out-of-scope classes — hash-randomized inputs, beyond-envelope sizes, round-trip fidelity the oracle itself lacks — are verified structurally against gently's own invariants instead of byte-wise against the oracle, and no spec may state unqualified byte-equality with the oracle. | [[ge.oracle]] | |

## Model

### States

- `clean`
- `verified`
- `stale`
- `oracle_missing`

### Transitions

| id | from | to | guard |
|----|------|----|-------|
| t1 | clean | verified | [[ge.oracle.c1]] |
| t2 | clean | oracle_missing | [[ge.oracle.c1]] |
| t3 | verified | stale | [[ge.oracle.c2]] |
| t4 | stale | clean | [[ge.oracle.c3]] |

### Failure terminal

`oracle_missing` is a failure terminal: it emits [[ge.oracle.c4]].

## Requirements

### Requirement: Property coverage mirror

Every property row SHALL be verified by exactly one dedicated scenario;
`ah sync` SHALL derive one contract per VERIFIES link.

#### Scenario: p1

- **WHEN** fixture headers recorded by the oracle runner
- **THEN** every header names the pinned version and commit; none carries a foreign pin
- **VERIFIES** [[ge.oracle.p1]]

#### Scenario: p2

- **WHEN** arbitrary fixture inputs across all supported formats
- **THEN** every input/format pair has exactly one recorded expected output and no orphans
- **VERIFIES** [[ge.oracle.p2]]

#### Scenario: p3

- **WHEN** fixture corpus verified against recorded outputs
- **THEN** identical outputs pass; a single byte difference fails with input, format, and first differing line
- **VERIFIES** [[ge.oracle.p3]]

#### Scenario: p4

- **WHEN** environments missing perl, with a drifted Graph::Easy, and with stale pins
- **THEN** each case yields a typed error naming the missing piece and the remediation
- **VERIFIES** [[ge.oracle.p4]]

#### Scenario: p5

- **WHEN** record runs with matching and mismatching pins
- **THEN** new inputs are recorded and headers updated atomically; pin-less re-recording is rejected
- **VERIFIES** [[ge.oracle.p5]]

#### Scenario: p6

- **WHEN** the recorded corpus coverage matrix
- **THEN** every style, shape, group, direction, and label class appears in at least one fixture
- **VERIFIES** [[ge.oracle.p6]]

#### Scenario: p7

- **WHEN** the corpus stability and envelope probes over every fixture input
- **THEN** each fixture is classified hash-stable or hash-dependent and inside or outside the envelope; every byte-compat claim references only the stable, in-scope class, and the classification is machine-checkable by the repro-probe harness
- **VERIFIES** [[ge.oracle.p7]]
